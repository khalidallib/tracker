A simple real-time driver tracking web application built using JavaScript and Mapbox GL JS. This project allows users to view and track a driver’s live location directly on an interactive map interface.

## Overview

GoRide was created as a front-end mapping project to practice working with APIs, geolocation, and interactive UI features. The application focuses on providing a clean and simple user experience for tracking a driver in real time.

## Features

- Real-time location tracking
- Interactive Mapbox map integration
- Driver location centering
- Responsive user interface
- Simple and clean design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Mapbox GL JS
- Mapbox Directions API
