# GoRide Driver Tracker

GoRide is a real-time driver tracking web application that displays a driver’s live location using interactive maps. The project was built to practice working with APIs, geolocation features, and front-end web development.

# How to Install / Run

## 1. Clone the Repository

```bash
git clone https://github.com/yourusername/goride-driver-tracker.git
```

## 2. Open the Project

Open the project folder in VS Code or another code editor.

## 3. Run the Application

Open `index.html` in your browser.

For a better development experience, use the VS Code Live Server extension.
